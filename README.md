# pps-task

## Speaker setup

The "near" auditory condition (AN / ANT) is played on the **right** audio channel,
and the "far" condition (AF / AFT) is played on the **left** audio channel.

To get a real near/far effect, place the speakers accordingly:
- **right speaker** = near = in front of / close to the participant
- **left speaker** = far = behind the participant
